# Описание проекта

Данный проект представляет собой набор алгоритмов сортировки, реализованных на языке Python, а также утилиты для генерации случайных массивов и измерения времени выполнения сортировок.

## Структура проекта

- main.py: Главный скрипт, который генерирует случайный массив из 10000 чисел и измеряет время выполнения различных алгоритмов сортировки, выводя результаты и сравнения.

- sorts/: Папка с реализациями алгоритмов сортировки:
  - quicksort.py: Быстрая сортировка (Quicksort).
  - bubblesort.py: Пузырьковая сортировка (Bubblesort).
  - insertionsort.py: Сортировка вставками (Insertionsort).
  - stalinsort.py: Сортировка Сталина (Stalinsort) — нестандартный алгоритм, который сохраняет только возрастающую последовательность.

- utils/: Папка с утилитами:
  - utils.py: Содержит функции для генерации случайного массива (`generate_random_array`) и измерения времени выполнения сортировки (`start_timer`).

## Описание алгоритмов сортировки

- Quicksort: Эффективный алгоритм сортировки с разделением массива на подмассивы относительно опорного элемента.
- Bubblesort: Простой, но менее эффективный алгоритм, который многократно проходит по списку, меняя местами соседние элементы.
- Insertionsort: Алгоритм сортировки, который строит отсортированный массив по одному элементу за раз.
- Stalinsort: Алгоритм, который удаляет все элементы, нарушающие порядок возрастания, оставляя только возрастающую последовательность.

## Использование

Запуск main.py выполняет сортировки на одном и том же случайном массиве и выводит время работы каждого алгоритма, а также сравнения их производительности.
